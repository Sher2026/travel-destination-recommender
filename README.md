# Travel Destination Recommender

A lightweight, modular Python recommendation system built with `pandas` that filters travel destinations based on **budget** and **vibe**.

## Project Structure
```text
travel-destination-recommender/
├── data/
│   └── destinations.csv          # Dataset of destinations, budgets, and vibes
├── recommender/
│   └── travel_recommender.py     # TravelRecommender class logic
├── main.py                       # Entry point to run recommendations
├── requirements.txt              # Project dependencies
└── README.md                     # Project documentation
